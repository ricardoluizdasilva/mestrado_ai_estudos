# Tutorial Python — versão Colab-only

Esta versão foi preparada para utilização direta no Google Colab.
Ela também pode ser utilizada em Visual Code e no Jupyter Notebook.

## Características

- As imagens usadas nos capítulos estão incorporadas diretamente nos ficheiros `.ipynb`.
- Não é mais necessário carregar uma pasta `images`.
- Não é necessário executar uma célula de preparação para visualizar as imagens.
- Os ficheiros Python da pasta `examples` estão reunidos em `RLdS_Python_Examples.ipynb`, contudo, a recomendação é experimentá-los individualmente no formato `python (extensão py) - ficheiros originais encontram-se na pasta examples`. 

## Utilização no Colab

1. Abra o Google Colab.
2. Escolha **Ficheiro > Carregar notebook**.
3. Selecione o capítulo `.ipynb` pretendido.
4. O conteúdo e as imagens aparecem diretamente no notebook.
5. Execute apenas as células de código que quiser experimentar.

Esta distribuição foi criada a partir de `tutorial_python_v2`.
